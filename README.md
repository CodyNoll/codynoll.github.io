# Cody Noll - Software Engineering Portfolio

Portfolio website: **https://codynoll.github.io**

I'm a Griffith University computer science student majoring in Data Science and Artificial Intelligence, expecting to graduate in June 2027.

This repository contains the source for my software engineering portfolio website. It highlights university projects in Python, C++, computer vision, machine learning, automated reasoning, robotics, and testing.

## Featured projects

- **Detection-Assisted Visual Tracking:** Python/OpenCV tracking across 1,191 frames, with recovery from three tracking losses.
- **Hospital Readmission Prediction:** Python/C++ class-weighted SVM implementations evaluated on 99,343 hospital encounters.
- **Logic and Automated Reasoning:** Python first-order logic proof search and benchmarks. [Explore the source](https://github.com/CodyNoll/3806A1).
- **Electricity Tariff Billing and Test Suite:** Time-of-use billing logic and 40 passing automated tests (team project; individual contribution described on the website).
- **Autonomous Visual Search Robot:** Computer vision and target recognition contributions to a Webots team project that completed six recorded missions.

## Website

The site is a responsive, self-contained HTML/CSS/JavaScript page in [index.html](./index.html), designed to be hosted with GitHub Pages from the `main` branch root.

The full source code for every featured university project is not yet public. Project summaries distinguish individual work from team contributions.
